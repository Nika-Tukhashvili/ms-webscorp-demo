# Making Science — Website Assistant Demo

Internal demo page for the GeCX website assistant (CX Agent Studio, project `ms-webscorp-pre`).

- `index.html` — static page with the chat widget embed.
- Before the widget connects: paste the real `deploymentName` from
  CX Agent Studio → Deploy → Web widget → Integrate, and make sure this site's
  origin is in the deployment's domain allow-list.

Hosted via GitHub Pages (auto-deploys from `main`).
